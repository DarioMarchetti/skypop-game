# 海洋道具

`src/game/items.ts` 提供确定性的道具排程和 Canvas 图标。模块不依赖 React、游戏状态或 `Math.random`，因此同一个种子在不同客户端会得到相同路线。

## 排程

- 平台索引 `0..3` 永远没有道具。
- 第一个道具位于 `4..7`，由种子哈希决定。
- 后续道具间隔为 `5..8` 个平台，同样由哈希决定；索引超过 1023 时不生成。
- 道具类型按罗盘 40%、海螺 35%、珍珠 25% 加权。若抽到与上一个相同的类型，会按罗盘 → 海螺 → 珍珠 → 罗盘轮换，避免连续重复。

`itemAt(seed, index)` 按需扩展该种子的路线，而不是一次生成整条路线。模块缓存最多 8 个种子，每个种子最多缓存 1024 个平台；超过容量时淘汰最早使用的种子。哈希使用 32 位整数运算，输入种子会截断为整数。

## 道具效果

| 道具 | 持续 | 效果 |
| --- | ---: | --- |
| 潮汐罗盘 | 3 跳 | 显示预计落点 |
| 回声海螺 | 3 跳 | 接近中心时提供力度闪光和提示音 |
| 流星珍珠 | 5 跳 | 产生彩虹拖尾和落地星光，不额外加分 |

## 绘制 API

`drawItem(ctx, x, y, kind, timeMs, reducedMotion)` 绘制约 26px 的漂浮图标和可读的 12px 中文名：青蓝罗盘、珊瑚粉海螺、金色珍珠星环。`reducedMotion` 会关闭上下浮动。

`drawRainbowTrail(ctx, x, y, timeMs)` 绘制珍珠使用的短彩虹弧和星点。两个绘制函数都使用 `save/restore`，不会污染调用者的 Canvas 状态，也不保留粒子或动画状态。
