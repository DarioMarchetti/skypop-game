# 五种随机场景

每次开始新局选择一次场景，整局保持固定。首次在 5 种中等概率抽取，后续排除上一局，再从其余 4 种等概率抽取。用 sessionStorage 记住当前标签页的上次场景，刷新也避免重复；存储不可用时仍可正常开局。同一场景不会连续出现，但不保证每 5 局恰好各出现一次。

| 场景 | 背景与平台 | 掉落反馈 |
| --- | --- | --- |
| 岩浆 | 黑曜石、熔岩河、火星、裂纹岩台 | 熔岩喷溅、火星、暗烟，低沉爆裂声 |
| 高空 | 蓝天、层叠白云、云朵浮台 | 云雾扩散与穿云风线、风声 |
| 大海 | 海水渐变、波光、蓝色浮岛 | 水花抛射、扩散涟漪、落水声 |
| 冰块 | 冰晶、冰裂与雪、冰纹平台 | 放射裂纹、多边形碎冰、清脆冰晶声 |
| 藤蔓 | 森林叶片、悬藤、苔绿平台 | 断藤回弹、落叶飞散、沙沙声 |

## 实现
- sceneTypes.ts 定义场景、调色板与无连续重复选择函数。
- sceneBackground.ts、sceneFall.ts 分别绘制背景和 0.9 秒掉落效果。
- App 在实际新局创建时选择场景，GameCanvas 按场景绘制平台、蓄力颜色和掉落；音频使用不同频率及滤波。
- 掉落有 200ms 下坠过程，再播放效果，完成后结算；暂停会冻结过程。
- 所有场景复用相同的平台碰撞、跳跃、道具生成和服务端计分规则。
- 支持减少动态效果，不依赖图片下载。

## 验证
新增首局可达全部场景、后续能覆盖其余四种且不重复的 2 项测试，总计 9 项测试通过。浏览器逐一查看五种背景与掉落后结算，并验证刷新开局的场景变化。音效逻辑检查通过，未进行人工听感评测。
